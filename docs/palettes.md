# Palette studies

Six options for the day, twilight, and night bands. The app layout and UI
accent stay the same so the band colors can be compared directly. No variant
is applied to the app yet.

[Contact sheet](palettes/contact-sheet.png) · [Swatch comparison](palettes/palette-swatches.png)

| ----------------------------------------- | --------- | --------- | --------- | ----------------------------------------------- |
| A. [Sky](palettes/01-sky.png)             | `#f8fbff` | `#e3f2fd` | `#bbdefb` | Current blue direction with a distinct twilight |
| B. [Porcelain](palettes/02-porcelain.png) | `#ffffff` | `#f1f5f9` | `#c3d3e6` | Most neutral; white day and cool grey twilight  |

| D. [Lemon](palettes/04-lemon.png)         | `#ffffff` | `#fff3b0` | `#c9dcf0` | White day with a clear yellow twilight          |
| E. [Golden hour](palettes/05-golden.png)  | `#fff6d8` | `#ffd68a` | `#8fa9c7` | Strongest warm option; amber UI accent          |
| F. [Ember dark](palettes/06-ember.png)    | `#f7f0ea` | `#e6d2c8` | `#b99f95` | Dark chrome, warm white/rose/brown bands        |

## Picking guide

- **Safest extension of the current look:** Sky.
- **Most neutral / least colorful:** Porcelain.
- **White plus a clear yellow signal:** Lemon.
- **Warmest light palette:** Golden hour.
- **Warm light palette with a softer transition:** Sunrise.
- **Dark mode:** Ember.

## Generation

The screenshots use the running app with only the CSS custom properties
overridden in the browser. No application code or persisted settings change.
The source screenshots are 1280×800.
